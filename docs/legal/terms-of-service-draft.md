# 利用規約（ドラフト）

Status: Draft / 専門家確認前。Issue #12 の「利用規約に含める事項」を整理した初版です。公開前に法務確認を行います。

## 1. 適用範囲

- 本規約は、IRLight のアカウント、Control Plane、Media Node、 destination Relay を含む IRLight が提供するサービスの利用に適用します。
- 有料βやイベントパスなどの個別条件がある場合は、本規約と合わせて適用します。矛盾がある場合は、個別条件を優先します。

## 2. ベストエフォートと停止

- IRLight はベストエフォートでサービスを提供し、完全な無停止を保証しません。
- メンテナンス、障害対応、セキュリティ対応、不正利用対策のため、予告なく機能制限・停止を行う場合があります。
- 配信プラットフォーム側の仕様・障害・レート制限・アカウント制限は IRLight の保証外です。

## 3. 配信権利と禁止行為

- ユーザーは、配信するコンテンツについて必要な配信権、出演許諾、音楽・映像利用許諾、第三者の権利処理を自己の責任で確保します。
- 以下を禁止します。
  - 違法コンテンツ、権利侵害コンテンツ、誹謗中傷、迷惑・ハラスメント目的の中継
  - 不正アクセス、内部ネットワーク探索、SSRF、認証情報総当たり、サービス妨害を目的とした利用
  - IRLight または第三者のサービス・インフラに過負荷を与える利用
  - アカウント・無料枠・イベントパスの automation による大量取得や再販
  - stream key、ingest credential、destination secret の共有・再利用・漏えい
- IRLight は、これらに該当すると判断した Session / Account を事前通知なく停止または削除できます。

## 4. 入力・素材・resource limit

- 入力コーデック、解像度、フレームレート、ビットレート、upload size・形式は IRLight が定める範囲内に制限されます。
- 規定外入力や高負荷が検出された場合、Ingest kick、Session 停止、upload 拒否、rate limit 適用が行われます。
- media / upload process には非 root 実行、read-only filesystem、CPU / memory / process / FD / file size / time limit を適用します（対応状況は脅威モデルの T04 / T05 を参照）。

## 5. 無料枠・イベントパス

- 無料試験は回数・同時利用数・時間に制限があります。
- メール確認、bot 対策、重複利用検知により、大量アカウントや使い捨てアカウントからの利用を制限する場合があります。
- イベントパスの有効期限、計上開始条件、延長条件は個別販売条件に従います。【要確認: 有効期限・計上条件の確定値】

## 6. 障害時の補填

- IRLight 側の障害による配信中断があった場合の補填は、契約・プランに定める上限と方法に従います。【要確認: 補填上限・方法】
- 配信プラットフォーム側障害、ユーザー環境、ネットワーク、権利侵害対応に起因する中断は補填対象外とします。
- 補填は金銭以外の方法（時間延長・クレジット等）となる場合があります。
- 返金の申請条件・金額・手数料はプラン・イベントパス・法令に従います。【要確認】

## 7. 録画・データ

- IRLight は標準では映像・音声を録画・保存しません。
- Destination 設定、暗号化された secret、待機素材、Session metadata、接続・切断・障害 event、利用量・決済・監査ログを保持します（保持期間はプライバシーポリシーおよびデータ保持・削除方針を参照）。

## 8. アカウント停止・データ削除

- 利用規約違反、不正利用、法令要請、セキュリティ incident への対応として、アカウント停止・Session 停止・データ削除を行う場合があります。
- データ削除・保持の詳細は `docs/operations/data-retention-deletion.md` およびプライバシーポリシーに従います。

## 9. 規約変更

- 本規約は必要に応じて変更します。重要な変更がある場合は、適切な方法で通知します。変更後の利用継続をもって同意とみなします。【要確認: 通知方法・経過措置】

## 10. 準拠法・管轄

- 本規約は日本法に準拠します。【要確認: 管轄合意裁判所】
